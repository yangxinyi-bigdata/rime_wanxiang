# 命名管道缓存状态同步系统使用指南

## 概述

`named_pipe_cached_sync.lua` 是一个高效的双向实时状态同步系统，它结合了应用层缓存和内核缓存机制，通过命名管道实现 Rime 输入法状态的实时同步。该系统支持双向通信：
- **正向管道**：Rime Lua → Python（状态推送）
- **反向管道**：Python → Rime Lua（命令控制）

## 功能特性

- **双向通信机制**：支持状态推送和命令控制的双向数据流
- **双层缓存机制**：结合应用层缓存和内核缓存，减少重复数据传输
- **去重优化**：自动检测并过滤重复的状态数据
- **批处理支持**：支持批量写入，提高传输效率
- **JSON 格式**：使用标准 JSON 格式传输状态数据和命令
- **非阻塞设计**：采用非阻塞模式，不影响输入法性能
- **智能检测**：自动检测读取端和写入端的存在状态

## 系统架构

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  Rime Context   │───▶│  Lua 缓存系统    │───▶│  正向管道       │
│  (输入法状态)   │    │  (去重+批处理)   │    │  (/tmp/rime_    │
└─────────────────┘    └──────────────────┘    │   state_pipe)   │
                                                └─────────────────┘
                                                         │
                                                         ▼
                                                ┌─────────────────┐
                                                │  Python 客户端  │
                                                │  (读取状态)     │
                                                └─────────────────┘
                                                         │
                                                         ▼
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  Lua 命令处理   │◀───│  Lua 反向读取    │◀───│  反向管道       │

                                                └─────────────────┘
```

## API 函数参考

### 核心初始化函数

#### `M.init()`
- **功能**：初始化整个同步系统，包括正向和反向管道
- **返回值**：`boolean` - 初始化成功返回 `true`
- **使用示例**：
```lua
local sync_module = require("named_pipe_cached_sync")
if sync_module.init() then
    print("系统初始化成功")
end
```

#### `M.fini(env)`
- **功能**：清理系统资源，关闭管道并删除管道文件
- **参数**：`env` - 环境对象（可选）
- **使用示例**：
```lua
sync_module.fini(env)
```

### 管道初始化函数

#### `M.init_pipe_cache()`
- **功能**：初始化正向管道（Lua写入，Python读取）
- **返回值**：`boolean` - 初始化成功返回 `true`
- **管道路径**：`/tmp/rime_state_pipe`

#### `M.init_reverse_pipe()`
- **功能**：初始化反向管道（Python写入，Lua读取）
- **返回值**：`boolean` - 初始化成功返回 `true`
- **管道路径**：`/tmp/rime_reverse_pipe`

### 状态同步函数

#### `M.update_state_cached(context)`
- **功能**：更新并同步 Rime 输入法状态，同时处理反向管道数据
- **参数**：`context` - Rime 上下文对象
- **返回值**：`boolean` - 更新成功返回 `true`
- **使用示例**：
```lua
-- 在状态更新回调中使用
env.update_notifier = context.update_notifier:connect(function(ctx)
    sync_module.update_state_cached(ctx)
end)
```

#### `M.serialize_state(state)`
- **功能**：将状态对象序列化为 JSON 字符串
- **参数**：`state` - 状态数据表
- **返回值**：`string` - JSON 字符串，失败返回 `nil`

### 正向管道写入函数

#### `M.write_to_pipe_cached(data)`
- **功能**：带缓存的管道写入，支持去重和批处理
- **参数**：`data` - 要写入的数据字符串
- **返回值**：`boolean` - 写入成功返回 `true`

#### `M.safe_write_to_pipe(data)`
- **功能**：安全写入，检查读取端存在后再写入
- **参数**：`data` - 要写入的数据字符串
- **返回值**：`boolean` - 写入成功返回 `true`

#### `M.write_to_pipe_direct(data)`
- **功能**：直接写入管道，不进行检查
- **参数**：`data` - 要写入的数据字符串
- **返回值**：`boolean` - 写入成功返回 `true`

### 反向管道读取函数

#### `M.read_from_reverse_pipe()`
- **功能**：从反向管道读取数据
- **返回值**：`string` - 读取到的数据，无数据返回 `nil`

#### `M.parse_reverse_data(data)`
- **功能**：解析从 Python 端接收的 JSON 数据
- **参数**：`data` - JSON 字符串
- **返回值**：`table` - 解析后的数据表，失败返回 `nil`

#### `M.handle_reverse_command(parsed_data)`
- **功能**：处理从 Python 端接收的命令
- **参数**：`parsed_data` - 解析后的命令数据
- **返回值**：`boolean` - 处理成功返回 `true`
- **支持的命令**：
  - `ping`：心跳检测

#### `M.process_reverse_pipe()`
- **功能**：处理反向管道数据的完整流程（读取→解析→处理）
- **返回值**：无返回值

### 检测函数

#### `M.has_pipe_reader()`
- **功能**：检查正向管道是否有 Python 读取端

- **返回值**：无返回值

#### `M.force_flush_cache()`
- **功能**：强制刷新所有缓存
- **返回值**：无返回值

### 批处理函数

#### `M.flush_batch_to_pipe()`
- **功能**：将批处理缓冲区的数据刷新到管道
- **返回值**：无返回值

### 统计和状态函数

#### `M.get_cache_stats()`
- **功能**：获取缓存统计信息
- **返回值**：`table` - 包含统计数据的表

#### `M.manual_process_reverse_pipe()`
- **功能**：手动处理反向管道数据

- **功能**：获取反向管道的文件路径

## 数据格式说明

### 正向管道数据格式（Lua → Python）

系统传输的状态 JSON 数据格式如下：

```json
{
  "is_composing": true,
  "input_mode": "chinese",
  "input_text": "nihao",
  "timestamp": 1673856000000
}
```

#### 字段说明

- `is_composing`: 是否正在输入（布尔值）
- `input_mode`: 输入模式（"chinese" 或 "ascii"）
- `input_text`: 当前输入的文本
- `timestamp`: 时间戳（毫秒）

Python 端可以发送的命令 JSON 格式：

```json
{
  "command": "ping",

  "data": {}
```


## Python 端实现

### 1. 反向管道写入（Python → Lua）

```python
import json
import os
import time
from typing import Dict

class RimeCommandSender:
    def __init__(self, reverse_pipe_path: str = "/tmp/rime_reverse_pipe"):
        self.reverse_pipe_path = reverse_pipe_path
        self.reverse_pipe_fd = None
        
    def connect(self) -> bool:
        """连接到反向管道"""
        try:
            # 以写入模式打开反向管道
            self.reverse_pipe_fd = os.open(self.reverse_pipe_path, os.O_WRONLY | os.O_NONBLOCK)
            return True
        except OSError as e:
            print(f"连接反向管道失败: {e}")
            return False
    
    def send_command(self, command: str, data: Dict = None) -> bool:
        """发送命令到 Lua 端"""
        if not self.reverse_pipe_fd:
            return False
            
        try:
            command_data = {
                "command": command,
                "timestamp": int(time.time() * 1000),
                "data": data or {}
            }
            
            json_str = json.dumps(command_data) + "\n"
            os.write(self.reverse_pipe_fd, json_str.encode('utf-8'))
            return True
        except OSError as e:
            print(f"发送命令失败: {e}")
            return False
    
    def ping(self) -> bool:
        """发送心跳命令"""
        return self.send_command("ping")
    
    def get_status(self) -> bool:
        """请求状态查询"""
        return self.send_command("get_status")
    
    def clear_cache(self) -> bool:
        """清理缓存"""
        return self.send_command("clear_cache")
    
    def close(self):
        """关闭连接"""
        if self.reverse_pipe_fd:
            os.close(self.reverse_pipe_fd)
            self.reverse_pipe_fd = None

# 使用示例
def main():
    sender = RimeCommandSender()
    
    if not sender.connect():
        print("无法连接到反向管道")
        return
    
    # 发送心跳
    if sender.ping():
        print("心跳发送成功")
    
    # 请求状态
    if sender.get_status():
        print("状态查询请求已发送")
    
    # 清理缓存
    if sender.clear_cache():
        print("缓存清理命令已发送")
    
    sender.close()

if __name__ == "__main__":
    main()
```

### 2. 正向管道读取（Lua → Python）

#### 基本读取示例

```python
import json
import os
import time
from typing import Dict, Optional

class RimeStateReader:
    def __init__(self, pipe_path: str = "/tmp/rime_state_pipe"):
        self.pipe_path = pipe_path
        self.pipe_fd = None
        
    def connect(self) -> bool:
        """连接到命名管道"""
        try:
            # 以非阻塞模式打开管道
            self.pipe_fd = os.open(self.pipe_path, os.O_RDONLY | os.O_NONBLOCK)
            return True
        except OSError as e:
            print(f"连接管道失败: {e}")
            return False
    
    def read_state(self) -> Optional[Dict]:
        """读取一条状态数据"""
        if not self.pipe_fd:
            return None
            
        try:
            # 读取数据
            data = os.read(self.pipe_fd, 1024)
            if data:
                # 解析 JSON
                json_str = data.decode('utf-8').strip()
                return json.loads(json_str)
        except (OSError, json.JSONDecodeError) as e:
            # 非阻塞读取可能返回空数据，这是正常的
            pass
            
        return None
    
    def close(self):
        """关闭连接"""
        if self.pipe_fd:
            os.close(self.pipe_fd)
            self.pipe_fd = None

# 使用示例
def main():
    reader = RimeStateReader()
    
    if not reader.connect():
        print("无法连接到 Rime 状态管道")
        return
    
    print("开始监听 Rime 状态...")
    
    try:
        while True:
            state = reader.read_state()
            if state:
                print(f"状态更新: {state}")
                
                # 根据状态执行相应操作
                if state.get('is_composing'):
                    print(f"正在输入: {state.get('input_text')}")
                    print(f"候选词数量: {state.get('candidate_count')}")
                else:
                    print("输入完成")
            
            time.sleep(0.01)  # 10ms 轮询间隔
            
    except KeyboardInterrupt:
        print("\n停止监听")
    finally:
        reader.close()

if __name__ == "__main__":
    main()
```

#### 异步读取示例

```python
import asyncio
import json
import os
from typing import Dict, Optional, Callable

class AsyncRimeStateReader:
    def __init__(self, pipe_path: str = "/tmp/rime_state_pipe"):
        self.pipe_path = pipe_path
        self.running = False
        self.callbacks = []
        
    def add_callback(self, callback: Callable[[Dict], None]):
        """添加状态变化回调"""
        self.callbacks.append(callback)
    
    async def start_listening(self):
        """开始异步监听"""
        self.running = True
        
        try:
            # 创建管道文件描述符
            pipe_fd = os.open(self.pipe_path, os.O_RDONLY | os.O_NONBLOCK)
            
            while self.running:
                try:
                    data = os.read(pipe_fd, 1024)
                    if data:
                        json_str = data.decode('utf-8').strip()
                        state = json.loads(json_str)
                        
                        # 调用所有回调
                        for callback in self.callbacks:
                            callback(state)
                            
                except (OSError, json.JSONDecodeError):
                    pass
                
                await asyncio.sleep(0.01)
                
        except OSError as e:
            print(f"监听失败: {e}")
        finally:
            if 'pipe_fd' in locals():
                os.close(pipe_fd)
    
    def stop(self):
        """停止监听"""
        self.running = False

# 使用示例
async def main():
    reader = AsyncRimeStateReader()
    
    # 添加状态处理回调
    def on_state_change(state: Dict):
        print(f"异步状态更新: {state}")
        
        if state.get('is_composing'):
            print(f"输入模式: {state.get('input_mode')}")
            print(f"当前输入: {state.get('input_text')}")
        
    reader.add_callback(on_state_change)
    
    # 开始监听
    print("开始异步监听...")
    await reader.start_listening()

if __name__ == "__main__":
    asyncio.run(main())
```

#### 高级功能：状态过滤和处理

```python
import json
import os
import time
from typing import Dict, Optional, Set
from dataclasses import dataclass

@dataclass
class RimeState:
    is_composing: bool
    input_mode: str
    input_text: str
    candidate_count: int
    schema_name: str
    timestamp: int
    
    @classmethod
    def from_dict(cls, data: Dict) -> 'RimeState':
        return cls(
            is_composing=data.get('is_composing', False),
            input_mode=data.get('input_mode', 'chinese'),
            input_text=data.get('input_text', ''),
            candidate_count=data.get('candidate_count', 0),
            schema_name=data.get('schema_name', ''),
            timestamp=data.get('timestamp', 0)
        )

class RimeStateProcessor:
    def __init__(self, pipe_path: str = "/tmp/rime_state_pipe"):
        self.pipe_path = pipe_path
        self.pipe_fd = None
        self.last_state: Optional[RimeState] = None
        self.interested_schemas: Set[str] = set()
        
    def add_schema_filter(self, schema_name: str):
        """添加感兴趣的方案过滤器"""
        self.interested_schemas.add(schema_name)
    
    def connect(self) -> bool:
        try:
            self.pipe_fd = os.open(self.pipe_path, os.O_RDONLY | os.O_NONBLOCK)
            return True
        except OSError:
            return False
    
    def process_states(self):
        """处理状态变化"""
        if not self.pipe_fd:
            return
            
        try:
            data = os.read(self.pipe_fd, 1024)
            if data:
                json_str = data.decode('utf-8').strip()
                state_dict = json.loads(json_str)
                current_state = RimeState.from_dict(state_dict)
                
                # 方案过滤
                if (self.interested_schemas and 
                    current_state.schema_name not in self.interested_schemas):
                    return
                
                # 状态变化检测
                if self.last_state:
                    self._handle_state_change(self.last_state, current_state)
                
                self.last_state = current_state
                
        except (OSError, json.JSONDecodeError):
            pass
    
    def _handle_state_change(self, old_state: RimeState, new_state: RimeState):
        """处理状态变化"""
        # 输入模式切换
        if old_state.input_mode != new_state.input_mode:
            print(f"输入模式切换: {old_state.input_mode} -> {new_state.input_mode}")
        
        # 开始输入
        if not old_state.is_composing and new_state.is_composing:
            print("开始输入")
        
        # 结束输入
        if old_state.is_composing and not new_state.is_composing:
            print("结束输入")
        
        # 输入文本变化
        if old_state.input_text != new_state.input_text:
            print(f"输入变化: '{old_state.input_text}' -> '{new_state.input_text}'")
        
        # 候选词数量变化
        if old_state.candidate_count != new_state.candidate_count:
            print(f"候选词数量: {old_state.candidate_count} -> {new_state.candidate_count}")
    
    def close(self):
        if self.pipe_fd:
            os.close(self.pipe_fd)
            self.pipe_fd = None

# 使用示例
def main():
    processor = RimeStateProcessor()
    
    # 只关注特定的输入方案
    processor.add_schema_filter("wanxiang_pro")
    processor.add_schema_filter("wanxiang_radical")
    
    if not processor.connect():
        print("连接失败")
        return
    
    print("开始处理状态变化...")
    
    try:
        while True:
            processor.process_states()
            time.sleep(0.01)
    except KeyboardInterrupt:
        print("\n停止处理")
    finally:
        processor.close()

if __name__ == "__main__":
    main()
```

### 3. 双向通信完整示例

```python
import asyncio
import json
import os
import time
from typing import Dict, Optional

class RimeBidirectionalClient:
    def __init__(self, 
                 state_pipe: str = "/tmp/rime_state_pipe",
                 command_pipe: str = "/tmp/rime_reverse_pipe"):
        self.state_pipe = state_pipe
        self.command_pipe = command_pipe
        self.state_fd = None
        self.command_fd = None
        self.running = False
        
    def connect(self) -> bool:
        """连接双向管道"""
        try:
            # 连接状态读取管道
            self.state_fd = os.open(self.state_pipe, os.O_RDONLY | os.O_NONBLOCK)
            # 连接命令写入管道
            self.command_fd = os.open(self.command_pipe, os.O_WRONLY | os.O_NONBLOCK)
            return True
        except OSError as e:
            print(f"连接失败: {e}")
            return False
    
    def send_command(self, command: str, data: Dict = None) -> bool:
        """发送命令到 Lua"""
        if not self.command_fd:
            return False
            
        try:
            command_data = {
                "command": command,
                "timestamp": int(time.time() * 1000),
                "data": data or {}
            }
            json_str = json.dumps(command_data) + "\n"
            os.write(self.command_fd, json_str.encode('utf-8'))
            return True
        except OSError:
            return False
    
    def read_state(self) -> Optional[Dict]:
        """读取状态"""
        if not self.state_fd:
            return None
            
        try:
            data = os.read(self.state_fd, 1024)
            if data:
                json_str = data.decode('utf-8').strip()
                return json.loads(json_str)
        except (OSError, json.JSONDecodeError):
            pass
        return None
    
    async def start_monitoring(self):
        """开始双向监控"""
        self.running = True
        last_ping = 0
        
        while self.running:
            # 读取状态更新
            state = self.read_state()
            if state:
                await self.handle_state_update(state)
            
            # 定期发送心跳
            current_time = time.time()
            if current_time - last_ping > 5:  # 每5秒发送一次心跳
                if self.send_command("ping"):
                    print("心跳发送成功")
                last_ping = current_time
            
            await asyncio.sleep(0.01)
    
    async def handle_state_update(self, state: Dict):
        """处理状态更新"""
        print(f"状态更新: {state}")
        
        # 根据状态变化发送不同命令
        if state.get('is_composing'):
            print(f"正在输入: {state.get('input_text')}")
            # 可以根据输入内容发送特定命令
            if len(state.get('input_text', '')) > 10:
                self.send_command("clear_cache")  # 输入过长时清理缓存
        else:
            print("输入完成")
    
    def stop(self):
        """停止监控"""
        self.running = False
    
    def close(self):
        """关闭连接"""
        if self.state_fd:
            os.close(self.state_fd)
        if self.command_fd:
            os.close(self.command_fd)

# 使用示例
async def main():
    client = RimeBidirectionalClient()
    
    if not client.connect():
        print("连接失败")
        return
    
    print("开始双向通信监控...")
    
    try:
        await client.start_monitoring()
    except KeyboardInterrupt:
        print("\n停止监控")
    finally:
        client.stop()
        client.close()

if __name__ == "__main__":
    asyncio.run(main())
```
